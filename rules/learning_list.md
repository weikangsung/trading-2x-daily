## 使用說明

### 規則狀態流轉
1. **待驗證 (0/10)**：新發現的規則，開始累計驗證次數
2. **驗證中 (X/10)**：持續驗證中，每次收盤後更新
3. **準備升級 (7+/10)**：驗證成功率 ≥ 70%，等待用戶確認升級
4. **已升級**：規則升級至 CLAUDE.md 主規則庫，移出此檔案
5. **已封存**：規則因系統改版而不再適用，保留供參考

### 何時添加規則
- 每次收盤檢討時，若發現新的交易規律，就添加新規則
- 規則應該具體、可量化、可重複驗證

## 規則 #027 — 財報季集中公布日：消息面 Agent 必須系統性掃描所有主要科技巨頭財報

- **規則內容**：每季財報集中公布週（通常為 1、4、7、10 月的第 3-5 週），若美東時間昨晚至台灣時間凌晨有多家主要科技公司同日公布財報，消息面 Agent 須**逐一確認每家財報的具體結果**，不可因已找到一家結果（尤其是負面消息）便停止搜集。特別關注：Microsoft（MSFT）、Amazon（AMZN）、Alphabet（GOOG）、Meta（META）、Apple（AAPL）、NVIDIA（NVDA）、AMD。
- **適用對象**：早盤消息面 Agent（Sub Agent 3）的信息收集流程
- **觸發條件**（早盤 8:00 前可確認）：
  - 今日（美東時間昨日下午至今日凌晨）有以下任一公司公布財報：MSFT、AMZN、GOOG、META、AAPL、NVDA、AMD
  - 或：為每季財報密集週（1、4、7、10 月）
- **要求行動**：
  1. 逐一搜尋並確認當日每家已公布財報的 EPS、營收、重要業務指引（如 Azure / AWS 成長率、AI 相關展望）
  2. 在消息面報告中明確列出「本日盤後財報清單」，每家公司附上正面/負面/中性評估
  3. 不因單一負面消息即認定市場情緒為「負面」，需待所有同日財報確認後綜合評估
